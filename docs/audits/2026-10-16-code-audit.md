## 修复

| 审查发现 | 修复 |
| --- | --- |
| 畸形数字字段可让中继在转换时抛错并退出 | 只接受有限原始数值；包解析和处理有异常边界，非法连接会关闭。 |
| 昵称和分数可作为 HTML 注入其他玩家页面 | 动态名称以纯文本或转义文本渲染；分数限定为有限数值并设上限。 |
| 已知玩家 ID 可冒充现有成员并接管房主身份 | 服务端为每个成员签发私有随机重连凭据；替换连接必须持有凭据，凭据只发给本人并按服务器、房间和玩家 ID 限定。 |
| 普通成员可发送暂停、延时、踢人和结束等房主管理命令 | 中继按房主身份校验管理命令，并拒绝非活动阶段的玩法消息。 |
| 移动消息可伪造其他玩家身份并制造残留假玩家 | 服务端绑定连接身份，规范化姓名、队伍、分数及坐标；越界或无效位置不再转发。 |
| 任意不存在的道具 ID 可消耗整局拾取额度 | 服务端只处理本房间实际生成的道具，并校验队伍、近期位置和地理距离。 |

额外修复了抓捕后缺少明确成功提示、被抓与逃脱玩家提示不清、旧计时器覆盖新提示、效果时长互相缩短、地图道具拾取距离误用经纬度方框、暂停状态和重连资料不同步等问题。重连会恢复房间认可的玩家资料和暂停状态，同时保留当前回合已消耗的技能。恢复已暂停的新页面时会重新启动定位或模拟移动。

服务端现在限制连接数、消息速率、房间成员及重连会话数量和慢客户端积压。共享的活动区域与道具规则放入 `shared/`，确保浏览器和中继使用同一坐标与道具种子。

## 边界
